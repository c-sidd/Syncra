# Glossary of Terms

This glossary is a living dictionary of key technologies and architectural concepts used throughout this course.

---

## 1. Relational Database & Django ORM Terms

* **ORM (Object-Relational Mapping)**: A programming technique that lets you interact with a relational database using your programming language's objects instead of writing raw SQL.
  * *Example*: `Folder.objects.all()` in Python translates internally to `SELECT * FROM folders;`.
* **Model**: A Python class that defines the structure of a database table, including fields (columns) and behaviors (methods).
* **Migration**: A file generated by Django that acts as a version-control instruction for your database. It defines how to alter tables (e.g., adding a column, creating a table) so that the database structure matches your Python models.
* **Foreign Key**: A database constraint that creates a link between two tables. It stores the primary key ID of a parent record in a child record's column.
* **Cascading Delete (`on_delete=models.CASCADE`)**: A rule stating that if a parent record (e.g., a folder) is deleted, all dependent children records (e.g., subfolders and files inside it) are automatically deleted as well.

---

## 2. API & Network Protocol Terms

* **API (Application Programming Interface)**: A set of defined rules that allows different software applications to communicate with each other.
* **HTTP (Hypertext Transfer Protocol)**: The underlying protocol used by the World Wide Web to define how messages are formatted and transmitted, and what actions web servers and browsers should take in response to commands.
* **REST (Representational State Transfer)**: An architectural style for designing networked applications. It uses standard HTTP verbs (GET, POST, PUT, DELETE) and is stateless.
* **JSON (JavaScript Object Notation)**: A lightweight, text-based data format that is easy for humans to read and write, and easy for computers to parse and generate. Used to send data between React and Django.
* **Endpoint**: A specific URL where an API can access the resources it needs to execute its function (e.g., `https://api.example.com/users/login/`).
* **CORS (Cross-Origin Resource Sharing)**: A security mechanism built into modern web browsers. It restricts web pages from making requests to a domain different from the one that served the page. We must configure Django to allow requests from our React app.
* **Serializer**: A component in Django REST Framework that converts complex data types (like database model instances) into clean JSON objects, and validates incoming JSON data to convert it back into Python data types.

---

## 3. Cloud Storage & AWS Terms

* **Bucket**: A public/private container (like a root folder) for storing objects in AWS S3. Bucket names must be globally unique across all AWS accounts.
* **Object**: A file and any metadata that describes it, stored inside an AWS S3 bucket.
* **Presigned/Signed URL**: A temporary, secure URL generated by the owner of an S3 bucket using cryptographic signatures. It allows restricted access to download/upload an object for a short period without sharing AWS credentials.

---

## 4. Frontend & React Terms

* **SPA (Single Page Application)**: A web application that loads a single HTML page and dynamically updates that page as the user interacts with the app, without requiring full page refreshes from the server.
* **Component**: A self-contained, reusable block of code that defines a piece of the user interface (UI) in React.
* **State**: A built-in object in React components that holds data that may change over time. When state changes, React re-renders the component to update the UI.
* **Props (Properties)**: Read-only inputs passed from a parent React component to a child component, allowing components to share data.
* **Hook**: A special function in React (like `useState` or `useEffect`) that lets you "hook into" React features like state management and lifecycle methods inside functional components.
* **Axios**: A promise-based HTTP client library for the browser and Node.js, used to make requests to our Django backend.
